# Yutong Wu · Academic homepage

The published site is [cuso4wyt.github.io](https://cuso4wyt.github.io/). This single-page site adapts the bio, paper list, and page layout from [Jon Barron's academic homepage](https://github.com/jonbarron/jonbarron.github.io), which the author makes available for personal use. The [customized GitHub fork](https://github.com/CuSO4wyt/academic-website) contains the same site.

Edit `index.html` to update the bio, news, research, projects, or background. `style.css` defines the layout and type. `script.js` handles navigation highlighting and the optional figure viewer. Open `index.html` in a browser or serve this directory locally. There is no build step.

The publishing repository uses GitHub Pages from the root of `main`. The bundled CV and paper PDFs are public. Font and school emblem credits are under `assets/`.
