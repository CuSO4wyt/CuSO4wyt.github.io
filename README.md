# Yutong Wu — personal website

Static personal academic website. No build step is required.

## Publish on GitHub Pages

1. Use the public repository `CuSO4wyt.github.io`.
2. Put this directory's contents in the repository root, with `index.html` at the top level.
3. In Settings > Pages, select Deploy from a branch, then `main` and `/ (root)`, and save.
4. Once the deployment finishes, open https://cuso4wyt.github.io/ .

The release contains the current CV and four paper PDFs linked by the website: EPT-Net (accepted at AIHCIR 2026) and three manuscripts under review. Those files become public when this release is published.

School emblem and font credits, including the font license, are included under `assets/`.

GitHub documentation: https://docs.github.com/en/pages/quickstart
