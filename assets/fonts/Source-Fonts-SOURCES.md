# Source web fonts

Source Sans 3 is used for body text, paper titles, navigation, and controls. Source Serif 4 is used for the English name and section headings. The Chinese name uses the existing system KaiTi stack.

- Font families: https://github.com/adobe-fonts/source-sans and https://github.com/adobe-fonts/source-serif
- Provider: Google Fonts, Latin subsets, variable weight 200–900. Retrieved 2026-11-19.
- Licenses: SIL Open Font License 1.1; see `Source-Sans-3-OFL.txt` and `Source-Serif-4-OFL.txt`.
- Bundled font files are unmodified. CSS loads local files first; the matching provider URLs support direct local-file previews.
