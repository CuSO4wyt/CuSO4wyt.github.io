# Computer Modern Sans

Web-font versions of CMU Sans Serif, based on Computer Modern, the family used by the supplied Beamer slides. Retrieved 2026-11-01.

- Web-font provider: https://github.com/bitmaks/cm-web-fonts
- Upstream font family: https://ctan.org/pkg/cm-unicode
- Source stylesheet: https://raw.githubusercontent.com/bitmaks/cm-web-fonts/master/font/Sans/cmun-sans.css
- License: SIL Open Font License 1.1, included in `Computer-Modern-OFL.txt`.
- Font files are unmodified.
